cuaderna

An agent works in steps. cuaderna writes every step to a journal, so a run that crashes continues where it stopped, and afterwards you can see what each step did and what it cost.

The runs listed here come from examples/fix_tests, an agent that asks a model to fix failing tests.

It is read in your browser and never uploaded. You can also drop a file on the page.
